
# Security Policy

Security is important to Snow Meowl projects.

## Reporting a Vulnerability

If you discover a potential security vulnerability, please report it privately rather than publishing technical details in a public issue.

Preferred method:

1. Open the affected repository on GitHub.
2. Navigate to the Security tab.
3. Look for the option to report a vulnerability privately.

This option is available only when private vulnerability reporting is supported and enabled for the repository.

If private reporting is unavailable, contact the maintainer through:

https://github.com/snow-meowl

Avoid publicly disclosing exploitable details before the issue has been assessed.

## What to Include

Please provide:

- The affected repository and version
- A description of the potential vulnerability
- Its potential impact
- Reproduction steps, where safe and appropriate
- Possible mitigations, if known

Do not include real passwords, access tokens, private keys, or other secrets in your report.

## Response

The maintainer will review reports as time and resources permit.

Please understand that response times and the availability of fixes may vary between projects.

## Supported Versions

Security support depends on the individual project. Check its README, release information, and documentation for supported versions.

## Disclosure

Please allow reasonable time to investigate and address a vulnerability before sharing details publicly.
