
# Contributing

Thank you for your interest in contributing to Snow Meowl projects!

These guidelines describe the general contribution process. Individual repositories may have additional requirements.

## Before You Start

- Read the project's README.
- Check existing issues and pull requests for duplicates.
- Review any project-specific contribution instructions.
- Make sure you understand the scope of your proposed change.

## Reporting Bugs

Use the Bug Report issue template whenever possible.

Include:
- A clear description of the problem
- Steps to reproduce it
- Expected and actual behavior
- Relevant versions, logs, or screenshots

## Suggesting Features

Use the Feature Request issue template.

Explain the problem your idea solves, the proposed solution, and any alternatives you considered.

## Submitting Changes

1. Fork the repository if needed.
2. Create a branch for your changes.
3. Make focused, understandable commits.
4. Test your changes using the project's documented procedures.
5. Update documentation when necessary.
6. Open a pull request describing your changes.

## Code Quality

- Follow the existing code style and project conventions.
- Keep changes focused on the intended problem.
- Avoid unrelated modifications.
- Do not include secrets, credentials, or private information.
- Add tests when appropriate and supported by the project.

## Pull Requests

Before submitting a pull request:

- Check your changes for unintended modifications.
- Run the available tests and checks.
- Explain what changed and why.
- Mention related issues when applicable.

## Respectful Collaboration

Be constructive, respectful, and open to feedback. All contributors are expected to follow the Code of Conduct.

Thank you for helping improve these projects!
