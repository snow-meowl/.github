
# Snow Meowl — GitHub Community Health Files

This repository contains shared community health files for projects maintained by [snow-meowl](https://github.com/snow-meowl).

## Contents

- Issue templates for bug reports and feature requests
- Pull request template
- Contribution guidelines
- Code of conduct
- Security policy
- Support information
- Funding configuration

## Purpose

These files help keep project contributions consistent, issues organized, and community guidelines clear across repositories.

## Usage

GitHub can use supported community health files from this repository as defaults for other public repositories owned by `snow-meowl`.

A repository's own files take precedence over these defaults.
